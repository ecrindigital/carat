# Space Invaders 2D

A simple Space Invaders clone built with the Carat game engine.

## Controls

- **LEFT/RIGHT** or **A/D** - Move player
- **SPACE** - Shoot

## Scoring

- Top row (Boss): 40 pts
- Second row (Red): 30 pts
- Third row (Yellow): 20 pts
- Bottom row (Green): 10 pts
